# Nutrition Dataset

Place the downloaded Kaggle CSV here:

```text
data/raw/nutrition/All_Diets.csv
```

Source:

```text
https://www.kaggle.com/datasets/thedevastator/healthy-diet-recipes-a-comprehensive-dataset
```

Expected columns include:

- `Diet_type`
- `Recipe_name`
- `Cuisine_type`
- `Protein(g)`
- `Carbs(g)`
- `Fat(g)`
- `Extraction_day`

The Kaggle page lists the license as `Other (specified in description)`. Keep the downloaded data local unless you have confirmed redistribution rights for your use case.
